# Simplified Chinese catalogs

The shell catalog matches the 572 keys shipped in this Omarchy A checkout.
It combines the Simplified Chinese translations from
[omacom/omarchy](https://github.com/omacom/omarchy/tree/quattro/default/i18n/zh-CN)
with translations of the remaining keys for this version. The menu catalog
comes from the same upstream directory. They retain the Omarchy shell's MIT
license (see `desktop/shell/LICENSE`). Catalogs are vendored and are not fetched
at login. Tests compare shell keys and numbered placeholders against English.
