# 学习记录的多用户服务器同步

这是 `math.ghtxx.cn` 后续增加的可选账号扩展，不是上游知识图谱的原生功能。
按机主选择，为多个家庭或学生提供独立账号；不与错题本账号混用，也不开放无邀请码注册。
代码在 `taxonomy-sync/`，数据集仍来自 TAXONOMY.md 中固定的上游提交，保留原署名与许可证。

## 用户流程

首次由机主在浏览器设置管理员账号与密码。初始化需要设备私有的一次性授权；
仅打开公共页面不能抢注管理员。完成后初始化令牌失效并删除。
管理员在账号页生成一次性邀请码，交给其他家庭或学生；每个邀请码七天有效、只能用一次。
每个用户只能读取和修改自己的记录，可管理多个孩子。

登录后先载入服务器记录，再启动原网页的档案与诊断代码。档案、诊断历史、
各学科进度、薄弱知识点及出过的题都会同步。换设备后登录同一账号即可载入。
页面上方显示同步状态；另一设备有更新时提示主动载入，避免正在答题时突然重载页面。

本机旧记录不会自动归到新账号。服务器为空时，可明确选择“导入此设备旧记录”；
服务器已有记录时先导出旧档案，再通过原有预览/确认导入功能合并，不自动覆盖。
本机与服务器同时修改时采用版本检查：返回冲突并保留待同步副本，不自动选择一方覆盖。
可导出本机记录，再载入服务器版本并合并档案。
同一浏览器只允许一个标签页编辑，防止共享 localStorage 导致两个页面相互覆盖。

断网期间已打开页面的修改暂存在当前账号的本机待同步副本，恢复联网后重试。
重新打开网站时仍需连接服务器确认账号。退出前必须完成同步或处理冲突。
不再按原页面的最近 40 次规则截断历史；每账号服务端快照上限 8 MB，超限时拒绝保存并提示导出，
不会假装已经同步成功。

## 存储与认证

- iPad 服务：`cn-math-taxonomy.service`，仍只监听回环端口 3002。
- 服务程序：`/opt/cn-math-taxonomy/taxonomy-server.py`。
- 活动静态页面版本：`/opt/cn-math-taxonomy/releases/276b88c4-accounts-v1`。
- 私有数据库：`/var/lib/cn-math-taxonomy/learning.sqlite3`，目录 0700、数据库 0600。
- 使用 SQLite WAL 和事务版本比较，服务器从登录会话确定用户，不接受客户端自报用户 ID。
- 密码采用随机盐和 PBKDF2-HMAC-SHA256（600000 次），不明文保存密码。
- 随机会话令牌只存哈希，使用 `__Host-`、Secure、HttpOnly、SameSite=Strict cookie，七天有效。
- 写入和私有读取都要求本站 Origin；私有读取使用 POST，避免旧版 service worker 缓存 GET 响应。
  新版 service worker 也明确跳过所有 `/api/`，私有 API 响应为 no-store。
- 登录/注册按入口地址限速；API 并行上限为 2，服务内存上限 160 MB，避免占满 2GB iPad。
- 新版启动脚本会备份旧本机数据；账号切换与退出清理当前可见学习缓存。
  冲突恢复副本留在本机，只有用户明确导出/载入才继续处理。

Cloudflare 只承载通道，不存这些学习记录。数据库和自动备份均在这台 iPad，
不是另一台云服务器；iPad 离线时无法从服务器载入账号。

## 自动备份与回退

`cn-math-backup.timer` 每日调用 `cn-math-backup.service`，使用 SQLite 在线备份接口，
保留最近七个日期的数据库副本，位于私有目录 `backups/`。已验证备份文件模式为 0600。
首次激活也执行了一次备份。未复制真实账号、学习记录、会话或初始化令牌到 Git。

旧静态版本与原 service 备份保留：
`/opt/cn-math-taxonomy/releases/276b88c4ff57`、
`/var/lib/omarchy-maintenance/cn-math-static.service`。
回退前应先备份私有数据库和待同步记录；不要删除数据库或把私有状态放进静态站点目录。
旧静态版不会读取新账号数据库，回退只用于恢复旧站点，不是数据降级迁移。

## 构建与验证

`taxonomy-sync/build-taxonomy-accounts.py` 接受固定上游 checkout 和一个尚不存在的输出目录。
它按原部署清单打包页面和数据，增加账号加载门控、同步脚本及账号页，关闭统计，
调整分享域名、缓存版本、隐私说明及历史保留；不会运行 npm 或上游发布脚本。

服务端七项回归测试覆盖：未登录拒绝、Origin 边界、账号隔离、一次性邀请与初始化关闭、
会话退出与过期、并发冲突、大小/格式限制及私有数据库备份。
`python3 taxonomy-sync/test_taxonomy_server.py` 可使用系统 Python 运行。

浏览器以仅存于临时目录的虚构账号验证：新增档案上传，清空本机缓存后从服务器恢复，
换账号不可见原档案，模拟另一设备写入后拒绝覆盖并保留本机待同步副本，
第二个编辑标签页被阻止。`run-taxonomy-preview.py` 是仅限 localhost 的临时测试夹具，
包括虚构会话入口，**绝不能部署到 iPad 或公网**；生产服务没有这些入口。
另验证保存 45 次记录不被原 40 次规则截断。

公网部署已验证健康检查与未登录私有读取返回 401；首次真实管理员仍由机主亲自设置，
不能把临时测试账号当作正式账号。实际初始化完成后再确认正式登录和同步。
